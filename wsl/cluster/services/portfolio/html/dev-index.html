Sobre este site

Este site e um portfolio interativo que funciona como uma demonstracao pratica de conceitos de Cloud e Kubernetes. Tudo aqui roda em um cluster Kubernetes real (criado com Kind dentro do WSL2), com servidor web nginx, banco de dados PostgreSQL e dashboard Grafana com metricas reais do cluster. O codigo completo esta versionado no GitHub — isso significa que qualquer pessoa com acesso ao repositorio pode recriar todo o ambiente do zero, incluindo este site.
